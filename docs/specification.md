# Спецификация Accounting Service

## Обзор домена

Продукт: Интернет-банк (backend)  
Целевая аудитория: Клиенты банка  
Основная функция: Управление счетами и транзакциями

Документация API: `src/main/resources/openapi.yaml` (единый источник истины)  
Swagger UI: http://localhost:8080/swagger-ui.html (после запуска приложения)

---

## Бизнес-требования

### BR-001: Управление счетами
Как клиент, я хочу открывать, пополнять и закрывать счета, чтобы управлять своими финансами.

Технологии: Spring Boot, JPA, Bean Validation  
Критерии приемки:
- Счет имеет уникальный ID, баланс, статус
- Баланс не может быть отрицательным
- Закрытие счета возможно только при нулевом балансе

### BR-002: Операции со счетами
Как клиент, я хочу выполнять пополнения, снятия и переводы, чтобы использовать свои средства.

Технологии: sealed interface Operation, records, @Transactional  
Критерии приемки:
- Сумма операции всегда положительная
- Снятие невозможно при недостаточном балансе
- Переводы атомарны (списание + зачисление в одной транзакции)

### BR-003: История операций
Как клиент, я хочу просматривать историю операций, чтобы контролировать расходы.

Технологии: Stream API, SQL JOIN, фильтрация по датам  
Критерии приемки:
- История сортируется по дате (новые сначала)
- Фильтрация по диапазону дат
- Отображение типа операции, суммы, времени

## Матрица соответствия технологий

| Бизнес-задача             | Технология                         | Обоснование                         |
|---------------------------|------------------------------------|-------------------------------------|
| Хранение данных           | PostgreSQL 17 + Flyway             | ACID, версионированные миграции     |

| Документация API          | OpenAPI 3.1 + springdoc-openapi    | Контракт как источник истины        |
| Тестирование              | JUnit Jupiter + Testcontainers     | Интеграционные тесты с реальной БД  |
| CI/CD                     | Jenkins + Docker                   | Автоматизация сборки и деплоя       |

## Нефункциональные требования

### Производительность
- Время ответа API: p95 < 200ms
- Поддержка 100 RPS на один инстанс

### Безопасность
- Аутентификация: JWT (Фаза 4)
- Авторизация: роли USER, ADMIN
- Маскирование PII в логах

### Надежность
- Идемпотентность операций (Фаза 2A)
- Health checks (Spring Actuator)

### Масштабируемость
- Stateless API (сессии не хранятся)
- Горизонтальное масштабирование через Docker

## Глоссарий

| Термин          | Определение                                               |
|-----------------|-----------------------------------------------------------|
| Account         | Банковский счет с балансом и статусом                     |
| Transaction     | Запись об операции (пополнение, снятие, перевод)          |
| Operation       | Команда на выполнение действия (sealed interface)         |
| PII             | Personally Identifiable Information (персональные данные) |
| Idempotency Key | Уникальный ключ для защиты от повторных запросов          |
