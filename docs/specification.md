# Спецификация Accounting Service

## Обзор домена

Продукт: Интернет-банк (backend)  
Целевая аудитория: Клиенты банка  
Основная функция: Управление счетами и транзакциями

Документация API: `src/main/resources/openapi.yaml` (единый источник истины)  
Swagger UI: http://localhost:8080/swagger-ui.html (после запуска приложения)

---

## Функциональные требования

Реализовать backend интернет-банка, позволяющий клиенту управлять одним или несколькими банковскими счетами через REST API — от открытия до закрытия, включая пополнение, снятие, переводы и просмотр истории операций.
Измеримые критерии успеха спринта:

    Клиент через API создает счёт с произвольным начальным балансом
    Клиент видит текущий баланс любого своего счёта
    Клиент пополняет счёт на любую положительную сумму
    Клиент снимает средства при достаточном балансе, получает ошибку при недостаточном
    Клиент переводит средства между двумя счетами атомарно
    Клиент получает выписку по счёту (полную и за период)
    Клиент закрывает счёт с нулевым балансом
    Все сценарии защищены Basic Auth и покрыты тестами (unit + integration)

### Шаг 2. Чтение баланса счета
GET /accounts/{id}/balance возвращает баланс счёта
Ответ содержит только баланс (без лишних полей)
Если счёт не существует — HTTP 404 с описанием ошибки
Если счёт существует — HTTP 200 с JSON {"balance": 1500.00}
Endpoint требует Basic Auth
